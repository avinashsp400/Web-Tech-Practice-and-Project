Summary

1. What is a Form?

-> Form is an HTML container.
-> It is used to collect data from the user.
-> Forms provide a User Interface (UI) to interact with an application.

-> Syntax:
	<form>

	</form>


2. UI (User Interface):
		-> UI means "the part of the application visible to the user."

	Example:
	    Login Form
	    Registration Form
	    Contact Form
	    Payment Form


3. CRUD Operations

| Operation | Meaning      | Example              |
| --------- | ------------ | -------------------- |
| Create    | Add New Data | Register Student     |
| Read      | View Data    | View Student Details |
| Update    | Modify Data  | Edit Profile         |
| Delete    | Remove Data  | Delete Account       |

-> Forms are mainly used to perform CRUD operations.


4. Form is a Container:
	
     -> A form can contain different controls like,
						Textbox
						Password Box
						Checkbox
						Radio Button
						Dropdown
						Textarea
						Button
						File Upload


5. Form Attributes:

=> id:
      -> Unique identifier.
      -> Used in CSS and JavaScript.
      -> Syntax: <form id="loginForm">


=> class:
      -> Used to apply the same style to multiple forms.
      -> Syntax: <form class="box">


=> name:
      -> Used for reference in JavaScript and server-side programming.
      -> <form name="studentForm">


6. method Attribute:
	-> It decides, how the form data is sent to the server.
	
	-> There are only 2 methods,
				1. GET
				2. POST

	-> Default method is GET.


7. GET Method:
	-> GET sends data as "Query String".
			
			Example:
				login.html?username=Rahul

	-> Characteristics,
			1. Data visible in URL
			2. Less secure
			3. Can be bookmarked
			4. Stored in browser history
			5. Can be cached
			6. Limited data

	-> We Cannot upload files.

8. Query String:
	-> Everything after "?" in URL.

		Example:
		     student.html?id=101&name=Ravi
	
	-> '?' => Starts Query String
	-> '&' => Separates multiple values


9. POST Method:
	-> POST sends data inside Form Body (Request Body).

		Example URL:
			login.jsp

	-> Username and password are "NOT visible".

	-> Characteristics,
			1. More secure
			2. Large amount of data
			3. Supports file upload
			4. No URL length limit
			5. Not stored in browser history
			6. Cannot be bookmarked
			7. Not cached


10. GET vs POST

| GET            | POST                  |
| -------------- | --------------------- |
| Query String   | Form Body             |
| Visible        | Hidden                |
| Less Secure    | More Secure           |
| Bookmark       | No Bookmark           |
| Cached         | Not Cached            |
| History        | No History            |
| Limited Data   | Large Data            |
| No File Upload | File Upload Supported |


11. Cache:
	-> Cache means, Temporary storage used to load data faster.

			Example:
				Browser stores
					-> Images
					-> CSS
					-> JavaScript
	-> If again you try to visit,
				Second visit
				      ↓
			       Loads from cache
				      ↓
			     Website becomes faster.


12. novalidate:
	-> Disables browser's default HTML validation.
	-> Syntax: 
		<form novalidate>
	
	-> Mostly used when developer writes custom validation.


13. Browser Validation:
		-> Without novalidate browser automatically checks required, email, number.

			Example:
			     Please fill out this field.

14. Custom Validation:
		-> Developer writes validation, is generally used.


15. action:
	-> Specifies where the form data should be submitted.
	-> Syntax: 
		<form action="login.jsp">
