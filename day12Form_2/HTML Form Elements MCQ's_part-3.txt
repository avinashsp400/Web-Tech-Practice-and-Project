1. Positive Lookahead:
   ```````````````````
(?=.*[A-Z]) → At least 1 Uppercase

(?=.*[0-9]) → At least 1 Number

(?=.*[\W]) → At least 1 Special Character

-> Positive Lookahead checks if something exists.

8. <meter> Tag:

--> What is "<meter>"?

-> <meter> is used to show a "measured value" within a range.
-> It displays "how much is used or available".

-> Syntax,
	<meter value="60" min="0" max="100"></meter>

-> Important Attributes,

| Attribute | Meaning          |
| --------- | ---------------- |
|  value    | Current value    |

|  min      | Minimum value    |

|  max      | Maximum value    |

|  low      | Low value limit  |

|  high     | High value limit |

|  optimum  | Best value       |

-> optimum attribute specifies the ideal or best value in a <meter> element.

	Example:

		<label>Battery:</label>
		<meter value="80" min="0" max="100"></meter>

	Output: 
		Battery Level = 80%

-> Real-Life Uses,
	- Battery Level
	- Disk Usage
	- Temperature
	- Fuel Level
	- Exam Score

-> Meter = Shows a Value (Current Status).



9. <progress> Tag:

-> What is <progress>?

	- <progress> is used to show task completion.
	- It displays how much work is completed.

	Syntax:
		<progress value="40" max="100"></progress>


Important Attributes

| Attribute | Meaning        |
| --------- | -------------- |
|  value    | Completed work |

|  max      | Total work     |


	Example:

		<label>Downloading:</label>
		<progress value="70" max="100"></progress>

	Output:
		Download = 70% Complete

-> Real-Life Uses,
	- File Download
	- File Upload
	- Loading Process
	- Installation Progress
	- Form Completion

-> Progress = Shows Task Completion.


-> Meter vs Progress

|  <meter>                                   |  <progress>                   |
| ------------------------------------------ | ----------------------------- |
| Shows a measured value                     | Shows task completion         |

| Example: Battery 80%                       | Example: Download 80%         |

| Has "min", "max", "low", "high", "optimum" | Mainly uses "value" and "max" |

| Current Status                             | Work Progress                 |


<meter> → Displays a value within a known range.
<progress> → Displays the progress of a running task.
