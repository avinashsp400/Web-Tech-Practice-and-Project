				HTML Text Formatting & Typography 
			===============================================

==> Text Formatting:
    ````````````````
1. <h1> to <h6> (Headings) : Used to create headings. <h1> is the biggest heading and <h6> is the smallest.

2. <p> (Paragraph) : Used to write a paragraph of text.

3. <blockquote> (Quote) : Used to display a long quotation from another source.


==> Design Mode Tags (Only Design):
    ```````````````````````````````

1. <b> : Makes the text bold.

2. <i> : Makes the text italic.

3. <u> : Underlines the text.

4. <strike> : Draws a line through the text. (Old tag)


==> Semantic (Meaningful) Tags :
    ````````````````````````````
1. <strong> : Marks important text. It usually appears bold.

2. <em> : Marks emphasized text. It usually appears italic.

3. <ins> : Shows newly inserted text. It is usually underlined.

4. <del> : Shows deleted or removed text with a strike line.


-> Semantic means providing some meaing to the browser about our content present in HTML element/tag.


==> Other Tags:
    ```````````
1. <sup> : Displays text slightly above the normal line (Superscript).

		Example: 5th → 5<sup>th</sup>

2. <sub> : Displays text slightly below the normal line (Subscript).

		Example: H₂O → H<sub>2</sub>O


==> Block Level Elements :
    ``````````````````````
	A block-level element always starts on a new line and takes the full width available from left to right by default.

	In simple words:
		"One block element occupies one complete line."

-> Even if there is enough space, the next element always starts on a new line.

-> <div> Tag:
   ``````````
	<div> is a "block-level container" used to group multiple HTML elements together for styling, layout, or scripting.


==> Inline Elements : 
    `````````````````
	An inline element displays content in the same line and takes only the width required by its content.

	In simple words:
		"An inline element does not start on a new line and occupies only the space it needs."

-> <span> Tag:
   ```````````
	<span> is an "inline container" used to style or modify a small part of text without creating a new line.


==> Typography (CSS):
    `````````````````
1. text-indent -> Adds space before the first line of a paragraph.

2. ::first-letter -> Styles only the first letter of a paragraph (Drop Cap effect).

3. letter-spacing -> Increases or decreases the space between letters.

4. word-spacing -> Increases or decreases the space between words.

5. line-height -> Controls the space between lines of text.

6. overflow: auto -> Shows a scrollbar only when the content is too large.

7. text-overflow: ellipsis -> Displays "..." when the text is too long to fit.



==> Font Styles: (Deprecated) no longer using or outdated.
    ````````````
<font> (Deprecated) : Used to change font size, colour, and style in old HTML. Today, CSS is used instead.


==> Web Safe Fonts: (web-safe font family)
    ```````````````

-> Serif : Font with small decorative(Tails) lines at the ends of letters.

			Example: Times New Roman

-> Sans-serif : Font without decorative(Tails) lines. Looks clean and modern.

			Example: Arial

-> Monospace : Every letter takes the same width.

			Example: Courier New


==> Color Formats:
    ``````````````
1. Color Name : Uses the colour name directly.

		Example: red

2. Shade Name: Uses a shade of a colour.

		Example: gray

3. Hex Code: Represents colours using hexadecimal values.

		Example: #FF0000


==> HTML Containers:
    ````````````````   
1. <fieldset> : Groups related form elements inside a box.

2. <legend> : Displays the title of a <fieldset>.
